# THE LOCAL FERMENT

依存関係なしで動く、5スライド構成のクラフトビールLPです。

## 確認方法

`index.html` をブラウザで開くだけで確認できます。スライド2には `assets/story-workshop.png`、スライド3には `assets/image13-8.webp` と `assets/89787_0.jpg` を使用しています。

## 差し替え箇所

- `index.html` のオンラインショップURL
- `index.html` のGoogle Maps URL
- `styles.css` の `hero-image` の画像URL
- スライド3の灯台背景は `assets/image13-8.webp`、小窓写真は `assets/89787_0.jpg`
- 商品情報、ABV、コピー、フッター表記

## スライド1の動画

作成した動画を `assets/hero-pour.mp4` として配置してください。対応ブラウザ向けに `assets/hero-pour.webm` も配置すると、WebMが優先されます。
動画は音声オン（ブラウザの自動再生制限時は操作後に有効化）・自動再生・ループ再生です。1ページ目の `SOUND ON/OFF` ボタンで切り替えられ、2ページ目へ移動すると音量が徐々に下がります。未配置時は既存の背景画像が表示されます。

## 操作

- マウスホイール / トラックパッド：横スライド移動
- スマートフォン：左右スワイプ
- `↑ ↓ ← →` / `PageUp` / `PageDown`：スライド移動
- 右側（スマートフォンは下部）のドット：任意のスライドへ移動
